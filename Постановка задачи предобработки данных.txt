2. Прикладное исследование
2.1 Постановка задачи предобработки данных
Предобработка данных – это ключевой этап проекта, поскольку качество исходных записей напрямую влияет на корректность обучения модели.
Цель предобработки – сформировать очищенный и структурированный набор данных, содержащий необходимые для моделирования признаки, а также пригодный для обучения модели прогнозирования заработной платы.
Постановка задачи:
Дано:
1.	Массив вакансий раздела «IT и связь», выгружаемый через API trudvsem.ru в формате JSON;
2.	Данные Росстата;
3.	Язык программирования – Python;
4.	Среда разработки – Google Colab;
5.	Инструменты и библиотеки предобработки: requests, pandas, spaCy, Transformers, scikit-learn.
Ограничения:
1.	API портала может иметь ограничения на частоту запросов и объём выгружаемых данных;
2.	Вакансии могут содержать пропуски в полях;
3.	Заработная плата может быть указана в разных форматах: в виде диапазона, одной суммы, с разной периодичностью (за месяц, час или смену);
4.	Ограниченные временные и вычислительные ресурсы для обработки больших массивов данных.
Критерий:
Основной критерий точности – это максимизация доли корректно обработанных записей, сохраняющих значимую информацию и пригодных для дальнейшего моделирования. Критерий можно записать следующей формулой:

K_(предобр.)=D_(корр.)/D_(общ.) →max,            (1)

где D_(корр.) – количество записей, содержащих корректные данные; D_(общ.) – общее количество исходных записей.
Требуется:
Обеспечить подготовку данных к анализу и моделированию с учётом ограничений и максимизации критерия.
Ожидаемый результат предобработки – таблица, содержащая очищенный текст вакансии, структурированные метаданные, нормализованные зарплатные признаки, которые в дальнейшем используются для построения модели.
